# Spec: 대시보드 (Dashboard)

## Requirements

- UI-1 기간을 1H / 6H / 24H / 7D / 30D로 전환하며 KPI·차트·트레이스를 본다.
- UI-2 백엔드 장애와 "트래픽 없음"을 구분해 보여준다 (연결 표시등 + 실패 배너).
- UI-3 모르는 값은 모른다고 표시한다: 비용 `계산 불가`, 백분위 `표본 추정`, 시계열 `구간 일부 누락`.
- UI-4 트레이스 표에서 provider·status 필터, 페이지 이동, 상세 모달, CSV 내보내기를 한다.
- UI-5 알림 규칙 생성·일시 중지·삭제, 수동 평가, 발동 이력을 대시보드에서 관리한다.
- UI-6 인증이 켜진 서버에서 401이 나면 API 키 입력을 안내한다.
- UI-7 헤더의 `API 키 관리`에서 공급자·관리자 키를 등록·교체·검증·삭제하고 공식 사용액/잔액을 본다. 키 평문을 화면·콘솔·오류에 출력하지 않는다.
- UI-8 연결 AI 카드에서 백엔드 PC의 도구별 공식 한도·컨텍스트 추정·로컬 기록 비용을 확인한다. 없는 값은 `확인 불가`/`계산 불가`이며 계정 전체 청구액으로 오인하지 않도록 출처를 표시한다.

### 동작 규칙

- 공급자 키 호출은 `api.ts`의 `/keys`, `/keys/{provider}/verify`, `/keys/spend`로만 보낸다. 등록·삭제·검증은 기존 서버 인증 키를 `X-API-Key`로 보내며, 공급자 키는 등록 POST 본문에만 들어간다. 공급자 키를 브라우저 저장소에 보관하지 않는다. 비밀번호 입력은 저장 성공 및 모달 닫기 시 비운다. 환경 변수 키는 삭제 버튼을 제공하지 않는다.
- 공급자 키 모달은 기존 `modal-overlay`/`modal-content`, `useModalFocus`를 재사용하여 포커스 가두기·Esc 닫기·호출 버튼으로 포커스 복귀를 제공한다. 기존 카드·버튼·입력 토큰으로 라이트/다크 및 좁은 화면을 지원한다.
- 키 등록·조회·검증 실패는 고정 오류 문구로 안내하며 서버의 오류/검증 상세를 그대로 표시하지 않는다. 401/403이면 기존 `ConnectionBanner`의 `API 키 입력`으로 서버 설정을 연다. 저장/삭제/검증 성공 후 키 상태와 대시보드 카드를 갱신한다.
- 공식 금액은 공급자가 보고한 통화로 표시한다(`formatProviderSpend`, USD는 기존 `formatUsd`). `/keys/spend`는 서버의 15분 캐시를 사용한다. 지원 API 없음·금액 없음·조회 실패는 `확인 불가`이며 실제 0 금액은 0으로 표시한다.
- 연결 AI는 `/metrics/connected_ais`를 기존 5초 폴링과 함께 읽는다. 이 조회 실패는 카드 오류 상태로 표시하며 기존 KPI·차트·트레이스의 갱신을 막지 않는다. 이전 카드 값을 현재 값처럼 남기지 않는다. 빈 연결 목록과 조회 실패·로딩을 구분한다.
- 카드 비용은 로컬 수집 기록 기준 USD다. 구독 비용은 `API 환산`과 `실제 청구 아님`을 명시한다. 모두 단가 미상인 기간은 `계산 불가`, 일부 미상인 경우 알려진 소계와 미상 건수를 함께 표시한다. 컨텍스트가 없으면 `계산 불가`, 공식 한도와 청구액이 없으면 `확인 불가`다. 값 없는 한도에 0% 진행 막대를 만들지 않는다. 공식 한도는 기준 시각·리셋·오래된 값 표시를 함께 보여준다.
- CSV는 현재 provider·status 필터와 선택한 기간(1H / 6H / 24H / 7D / 30D)을 반영한다. 내보내기 클릭 시각에서 해당 시간 수를 뺀 UTC 시각을 `+00:00`이 포함된 ISO-8601 `start_time`으로 전달한다. 페이지와 무관하게 조건에 맞는 최신 행부터 내보내며 기본 상한은 10,000건이다. CSV 버튼 안내에도 provider·상태·기간 조건을 명시한다.
- 데모 트래픽 버튼은 `/system/info`의 `environment`가 `production`이 아닐 때만 보인다 (`canGenerateDemoTraffic`). 정보를 못 받으면 숨긴다. 데모 데이터는 실제 수집 API로 들어가 집계·알림·CSV에 섞이기 때문이다.
- 5초 주기 폴링. 탭이 숨겨지면 멈추고, 다시 보이면 즉시 갱신 후 재개.
- 모든 시각은 API의 UTC 오프셋 문자열을 브라우저 로컬 시각으로 표시한다.
- `X-Total-Count` 헤더가 없으면(프록시가 숨긴 경우) 현재 페이지 행 수로 추정 — 헤더 없음을 0건으로 취급하지 않는다.
- 개발 서버 `http://localhost:3000`이 `/api`를 8000으로 프록시. 운영은 백엔드가 `frontend/dist`를 서빙.

- E2E 브라우저 테스트 자동화 → 이월: 컴포넌트 테스트(Vitest)까지만 CI에 있다.

## Areas of concern

- 버튼만 숨긴다. 쓰기 키가 있으면 운영에서도 API로 데모 데이터를 넣을 수 있다. `ENVIRONMENT` 기본값이 `development`라 `.env` 없이 띄운 운영 서버에서는 버튼이 보인다 (docker-compose와 `.env.example`은 `production`).
- 해결됨(v0.5.0): 운영 대시보드에 데모 트래픽 버튼 노출.
- API 키를 `localStorage`에 평문 저장한다. XSS가 생기면 키가 노출된다. 신뢰된 네트워크 전제의 편의 기능으로 유지할지 결정 필요.
