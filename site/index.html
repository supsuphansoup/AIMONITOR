AIMONITOR

클로드 코드(Claude Code)·코덱스(Codex)·코파일럿(Copilot)의 남은 한도와 사용량을 Windows 트레이 위젯으로 한눈에. 계정 여러 개도 나눠서, 프롬프트·응답 본문은 모으지 않고.

Windows용 무료 다운로드 GitHub에서 소스 보기

Windows 10/11 · Python 설치 필요 없음 · MIT 라이선스 오픈소스 · English

이런 분께

  • Claude Code의 5시간·주간 한도가 얼마나 남았는지 매번 /usage로 확인하기 번거로운 분
  • Claude Pro·Max, ChatGPT Plus·Pro 구독으로 Claude Code와 Codex를 함께 쓰며 사용량 한도를 자주 확인하는 분
  • 개인·회사 Claude 계정이나 Codex·Copilot을 함께 써서 어디서 얼마나 썼는지 헷갈리는 분
  • API 토큰 사용량과 비용을 보고 싶지만 프롬프트를 외부 SaaS에 넘기기는 싫은 분

주요 기능

  • 항상 위 위젯 — 도구별 남은 한도(%)와 리셋 시각, 오늘 사용량·비용을 화면 구석에. 트레이에서 숨기기·열기.
  • 계정별 분리 — 여러 Claude·Codex 설정 폴더를 모두 읽고 계정마다 나눠 보여 줍니다.
  • 정직한 숫자 — 공식 값이 없으면 지어내지 않고 확인 불가·계산 불가로 표시합니다. 추정치는 추정이라고 밝힙니다.
  • 메인 창 — 계정별 한도·사용량, 기록·차트(계정·모델별), 공급자 API 키와 공식 청구액·잔액.
  • 내 앱의 LLM 호출도 함께 — Python SDK나 HTTP API로 OpenAI·Anthropic·Gemini·Ollama 호출 기록을 같은 화면에서.
  • Windows 시작 시 자동 실행.

설치

  1. Releases에서 AIMONITOR-<버전>-windows-x64.zip을 받아 원하는 폴더에 풉니다.
  2. AIMONITOR\AIMONITOR.exe를 실행합니다.

코드 서명이 없어 처음 실행할 때 SmartScreen 경고가 뜰 수 있습니다. 추가 정보 → 실행을 누르세요. 데이터는 %USERPROFILE%\.aimonitor에 저장됩니다.

개인정보

  • 로컬 로그에서는 토큰·요청 수, 모델, 시각, 세션 ID와 계정 해시만 모읍니다. 프롬프트·응답 본문은 저장하거나 보내지 않습니다.
  • 밖으로 보내는 곳: Claude 사용량 조회(api.anthropic.com, 비공식 엔드포인트), 환율 API, 등록한 키의 공급자, 설정한 Webhook. 텔레메트리는 없습니다.
  • 공급자 API 키는 Windows DPAPI로 암호화합니다. 로컬 API는 127.0.0.1에서만 열립니다.

자주 묻는 질문

Claude Code 사용량과 남은 한도는 어떻게 확인하나요?

AIMONITOR를 켜 두면 Claude Code의 5시간·주간 한도 남은 비율과 리셋 시각이 위젯에 계속 표시됩니다. 매번 /usage를 입력하지 않아도 됩니다.

Codex 남은 한도도 보이나요?

네. Codex 세션 로그에 기록되는 한도 창을 읽어 남은 비율을 보여 줍니다.

무료인가요?

네. MIT 라이선스 오픈소스이며 결제나 가입이 필요 없습니다.

Mac이나 Linux에서도 되나요?

지금은 Windows 10/11용 데스크톱 앱만 제공합니다.
